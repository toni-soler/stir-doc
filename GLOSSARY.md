# Glossary

STIR: Sistema Transparente de Intercambio de Recursos, the marketplace.
osTRIS: economic protocol/reference implementation.
IDAX Core: public separately licensed binary runtime.
IDAX Shell: public authentication and frontend composition host.
IDAX Ledger: proof/anchor/evidence module.
Tenant: isolation scope, not automatically community.
Community: economic governance scope.
Owner: authenticated user who created a tenant-scoped listing.
AgreementSnapshot: future immutable contractual commitment source.
COMMITTED: osTRIS economic completion, not STIR acceptance.
